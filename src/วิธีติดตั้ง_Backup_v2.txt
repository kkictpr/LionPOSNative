ติดตั้ง Backup v2

1. คัดลอก backup_v2.ps1 ไปที่
   D:\Backup\SakuDataCenter\

2. คัดลอก BackupLionPOS_v2.bat ไปที่ Desktop
   (หรือแทนไฟล์เดิม)

3. หลังจากเทสผ่านในแต่ละวัน
   ดับเบิลคลิก BackupLionPOS_v2.bat

ระบบจะ:
- เช็ก Git อัตโนมัติ
- ถ้าไม่มี Git จะ Backup ทั้งโปรเจ็กต์
- สร้างไฟล์ LionPOS_YYYY-MM-DD_HHMMSS.zip
- บันทึก backup_history.csv
- เปิดโฟลเดอร์ Backup ได้ทันที
